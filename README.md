# construtora-forte
Site institucional responsivo para uma construtora, desenvolvido com HTML, CSS e JavaScript.
Construtora Forte

Projeto de site institucional responsivo desenvolvido com HTML5, CSS3 e JavaScript puro, criado para compor meu portfólio de desenvolvimento web.

Sobre o Projeto

A Construtora Forte é um projeto fictício criado para demonstrar habilidades em desenvolvimento front-end, com foco em layout moderno, responsividade e boas práticas de estruturação de código.

O site apresenta uma empresa de construção civil, destacando seus serviços, experiência no mercado, projetos realizados e diferenciais competitivos.

Funcionalidades
Menu de navegação responsivo
Menu hambúrguer para dispositivos móveis
Seção Hero com imagem de destaque
Apresentação dos serviços oferecidos
Seção institucional "Sobre Nós"
Galeria de projetos
Rodapé com diferenciais da empresa
Layout totalmente responsivo
Utilização de Bootstrap Icons
